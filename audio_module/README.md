# TruthLensAI — Audio Verification Module (`audio_module/`)

Dedicated multimodal audio verification subsystem for **TruthLensAI**, strictly separating **Acoustic Provenance** (AI-generated vs. Human voice) from **Factual Veracity** (Truth vs. Misinformation).

---

## 1. Architectural Philosophy

### Separation of Concerns
1. **Provenance Detection (Acoustic Forensics)**: Analyzes the raw acoustic waveform to determine whether the speech was produced by human vocal cords or generated by a synthetic text-to-speech / voice-conversion model.
2. **Factual Verification (Information Analysis)**: Transcribes the speech content to text, extracts verifiable propositions, filters conversational filler, and queries authoritative web and fact-checking sources via `pipeline.run_research_pipeline()`.
3. **Consistency Matrix**: Synthesizes both signals into a clean categorization:
   - `AI_NARRATED_VERIFIED_FACT`: Benign synthetic narration of true information (e.g. AI educator/newsreader).
   - `SYNTHETIC_DISINFORMATION`: Malicious deepfake voice delivering fabricated or false claims (Critical Risk).
   - `HUMAN_DISINFORMATION`: Authentic human speaker delivering false claims (Traditional Misinformation).
   - `HUMAN_AUTHENTIC_FACT`: Authentic human speaker delivering verified facts.
   - `UNCERTAIN_PROVENANCE_...`: When acoustic evidence is inconclusive or model is unavailable.

### Zero-Default Failsafe Rule
The system **never silently defaults to REAL or HUMAN**. If an audio file is corrupt, silent, unsupported, or if model inference encounters an error or boundary ambiguity, the system explicitly returns `UNCERTAIN` or `UNAVAILABLE` (`available=False`).

## 2. Model Card & Forensics Audit

### Selected Model: `mo-thecreator/Deepfake-audio-detection`
- **Base Architecture**: `Wav2Vec2ForSequenceClassification` (`facebook/wav2vec2-base`)
- **Weights**: 378.3 MB (`model.safetensors`, 95M parameters)
- **License**: Apache-2.0
- **Sampling Rate**: 16,000 Hz mono PCM float32
- **Class Mapping**:
  - `0`: `fake` $\rightarrow$ `AI_GENERATED`
  - `1`: `real` $\rightarrow$ `REAL`

### Calibrated Decision Boundaries
To avoid false certitude, raw softmax probabilities are mapped into three distinct confidence regimes:
$$\begin{cases}
P(\text{fake}) \ge 0.65 & \implies \mathbf{AI\_GENERATED} \\
P(\text{fake}) \le 0.35 & \implies \mathbf{REAL} \\
0.35 < P(\text{fake}) < 0.65 & \implies \mathbf{UNCERTAIN}
\end{cases}$$

### Documented Limitations & Unverified Claims
> [!WARNING]
> - **Self-Reported Accuracy**: The model creator reports 98.82% validation accuracy on their specific training corpus hold-out split.
> - **Cross-Vocoder Generalization Unverified**: Generalization performance against cutting-edge commercial voice clone engines (e.g., ElevenLabs v2/v3, OpenAI Voice, XTTS-v2, StyleTTS2, VALL-E) has not been independently evaluated by standard academic benchmarks.
> - **Acoustic Degradation**: Lossy compression (e.g. low-bitrate MP3/AAC) and heavy telephone audio bandpass filtering can introduce artifacts that degrade classifier confidence.
> - **Operational Guidance**: Provenance classifications should serve as investigative evidence rather than sole, incontrovertible judicial proof.

## 3. Supported Formats & Preprocessing

- **Formats Supported**: `.wav`, `.mp3`, `.m4a`, `.flac`, `.aac`, `.ogg`.
- **Decoding Engine**: FFmpeg subprocess streaming raw `s16le` PCM via stdout at 16 kHz mono float32, with built-in standard library `wave` fallback for uncompressed WAVs.
- **Silence & Truncation Guards**:
  - Checks duration $\ge 0.5$ seconds (`MIN_AUDIO_DURATION_SEC`).
  - Measures Root Mean Square (RMS) energy against threshold $10^{-4}$ (`SILENCE_RMS_THRESHOLD`). Silent or near-silent files raise `SilentAudioError`.
- **4 GB GPU VRAM Protection**: Long audio is processed via sliding 10-second windows with mean probability aggregation, preventing quadratic attention memory spikes on consumer GPUs (e.g. NVIDIA RTX 3050 Laptop).

## 5. Usage Guide

### Programmatic Python API
```python
from audio_module import verify_audio

# Basic acoustic verification and speech transcription (offline / fast)
result = verify_audio(
    audio_path="sample.mp3",
    verify_claims=False,
    whisper_model="base"
)

print("Voice Provenance:", result["synthetic_speech_detection"]["label"])
print("Transcription:", result["transcription"]["text"])
print("Primary Claim:", result["claim_extraction"]["primary_claim"])
print("Consistency Category:", result["consistency_analysis"]["category"])

# Full verification with live web fact-checking (requires network)
live_result = verify_audio(
    audio_path="sample.mp3",
    verify_claims=True,
    max_claims_to_verify=1
)
print("Factual Verdict:", live_result["factual_verification"]["verdict"])
print("Consistency Assessment:", live_result["consistency_analysis"]["description"])
```
